# Manuel d'Utilisation - KIS Couveuse v1.0.0

Bienvenue dans votre application professionnelle de gestion de couveuse. Ce guide vous aidera à maîtriser toutes les fonctionnalités pour optimiser votre production.

---

## 1. Démarrage et Activation (Mode Hybride)
Au premier lancement, l'application est verrouillée. Suivez ces étapes pour l'activer selon votre situation :

### 🛠️ Processus d'activation standard (En ligne)
1. **Enregistrement** : Saisissez votre **Nom** et votre **Téléphone**, puis cliquez sur "**Lancer l'activation**".
2. **Règlement** : Suivez les instructions Mobile Money (Orange, Moov ou Wave) affichées à l'écran.
3. **Validation** : Une fois le paiement envoyé, attendez la validation du gérant et cliquez sur "**Vérifier mon paiement**" pour débloquer l'app.

### 📶 Mode Sans Internet (Secours)
Si vous ne disposez pas de réseau lors de l'installation :
- Cliquez sur "**Activer manuellement**".
- Copiez l'**ID Appareil** affiché en haut de l'écran.
- Envoyez cet ID par **WhatsApp** au gérant (+223 69 80 13 21).
- Saisissez la **Clé de déverrouillage** qu'il vous renverra.

## 2. Le Tableau de Bord (Accueil)
C'est le centre de pilotage de votre activité.
- **Sélection Rapide** : Cliquez sur l'image d'une volaille (Poule, Dinde, etc.) pour ouvrir un nouveau dépôt pré-rempli.
- **Alertes Mirages** : Affiche le nombre de dépôts qui doivent être vérifiés aujourd'hui.
- **Alertes Éclosions** : Affiche les dépôts arrivant à terme (moins de 3 jours restants).
- **Notifications** : Vous recevrez des alertes sur votre téléphone même si l'application est fermée. Cliquez sur une notification pour ouvrir l'app.

## 3. Gestion des Dépôts
Pour enregistrer une nouvelle couvée :
1. Cliquez sur **➕ Nouveau** ou sur une icône de volaille.
2. Choisissez le **Client**. Si c'est un nouveau client, enregistrez-le d'abord (vous serez ramené au dépôt automatiquement).
3. Saisissez la **Quantité** d'œufs. Le montant total se calcule tout seul.
4. **Mirage** : Revenez sur le dépôt après 7 jours pour saisir le **RAM** (Restant Après Mirage).
5. **Éclosion** : Une fois les poussins nés, saisissez le **Nombre éclos** pour clôturer le suivi.

## 4. Clients et Bilans
- **Liste des Clients** : Retrouvez tous vos clients et leur historique.
- **Bilan Technique** : Cliquez sur **Bilan** pour voir les performances d'un client. Ce document ne contient aucune info financière et peut être partagé en PDF (icône rouge) ou imprimé.
- **WhatsApp** : Cliquez sur l'icône WhatsApp pour envoyer un récapitulatif technique complet (Espèce, quantité, mirage, éclosion) directement au client.

## 5. Statistiques de Performance
L'onglet **Stats** vous donne une vue globale :
- **Taux de réussite** : Calculé sur vos couvées terminées.
- **Chiffre d'Affaires** : Vos revenus réels (les clients "Internes" sont exclus pour ne pas fausser vos gains).
- **Graphiques** : Visualisez quelle espèce réussit le mieux dans votre couveuse.

## 6. Réglages et Apparence
- **Nom et Logo** : Personnalisez l'application avec le nom de votre établissement et votre logo.
- **Fond d'écran** : Changez l'image de fond pour une interface qui vous ressemble.
- **Seuils d'alerte** : Ajustez le nombre de jours avant le mirage ou l'éclosion.

## 7. Sauvegardes
- **Sauvegarde Journalière** : L'application crée automatiquement une copie de vos données chaque jour.
- **Restauration** : En cas de problème, vous pouvez revenir à une version précédente.
- **Import/Export Cloud** : Partagez votre base de données vers Google Drive ou WhatsApp pour la mettre en sécurité hors de votre téléphone.
